# Changelog / 更新记录

## 0.1.1 — 2026-10-15

- Write bilingual CLI output in UTF-8 even under ASCII/cp1252 Windows consoles. Add a regression test for the failure observed in GitHub Actions.
- 即使Windows控制台默认ASCII或cp1252，也使用UTF-8输出双语帮助；添加GitHub Actions发现问题的回归测试。

## 0.1.0 — 2026-10-15

- Native PTMP/IPC connection and 14 MCP tools, with bilingual descriptions.
- Device/link creation, PC IPv4 and IOS configuration, actual ping and show output, `.pkt` save/open, native PNG export.
- Local random credentials, Cisco `meta` integration, optional backed-up user registration for Windows Packet Tracer 8.0.
- English and Chinese documentation, a real MCP SVI example, protocol and MCP tests.

- 原生PTMP/IPC连接、14个双语MCP工具。
- 设备连线、PC和IOS配置、实际ping/show、工程保存打开、原生拓扑导出。
- 本机随机凭据、Cisco `meta`集成、Windows Packet Tracer 8.0带备份登记。
- 中英文文档、真实MCP SVI示例、协议与MCP测试。
